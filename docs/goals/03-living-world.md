# 03. 2차 목표: 기억하는 세계와 이야기

목표: 세계가 내가 한 일을 기억하게 하고, 그 위에 이어지는 사건, 숨은 장소, 세력과 동료, 메인 스토리 첫 장과 고대의 힘을 올린다. 다 되면 서리항에서 시작해 사건을 따라가고, 숨은 곳을 찾고, 세력에 들고, 동료와 함께 메인 첫 장의 스토리 보스까지 가는 한 판이 돌아간다.
지금 게임에 빠진 것: 상태에 "무슨 일이 있었나"를 남길 칸이 없어 이야기·궁금증·NPC·세계의 반응이 한 번 보고 끝난다.
모든 항목은 기본안이고 만들면서 바꿔도 된다. 숫자는 코드에 `[임시값]` 주석.

## 한 판의 흐름 (계획)
1. 오프닝은 그대로. 다만 오프닝에서 한 선택이 기억된다
2. 마을에서 사람들과 말을 섞으면 내가 한 일에 따라 소문이 바뀐다. 고유 의뢰 인물을 다시 찾아가면 다른 말을 한다
3. 길 위 사건이 이어진다: 길 위 → 마을 사람 → 던전·적. 일지의 "실마리"가 다음 단서를 한 줄로 알려 준다
4. 길 위 "샛길"로 숨은 장소를 찾으면 지도에 남고, 다음부터 마을에서 곁길로 바로 간다
5. 세력 하나에 들어가 세력 의뢰로 자리를 올린다
6. (서리항 사슬 끝부터) 이르사와 함께 다닌다
7. 메인 스토리 첫 장을 따라가 스토리 보스를 잡고, 고대의 힘 하나를 얻는다

## 구현 순서
각 단계가 끝나면 Taehun이 플레이해 보고 판단한다. ★에서는 멈추고 다음을 정한다.

| 단계 | 할 일 | 화면 | 끝나면 할 수 있는 것 |
|---|---|---|---|
| G0. 이야기 뼈대 | /brainstorm 후보 → Taehun이 고른다: 메인 한 줄, 고대의 힘이 무엇인지, 세력 1~2개와 영주 다툼의 관계, 이르사의 역할, 엔딩을 둘지. docs/world/story.md 를 만든다 | 없음 | 이후 모든 글이 같은 줄기를 따른다 |
| G1. 기억 장치 | 상태에 표식 목록. 이벤트 형식에 "남기기 / 있어야 나옴 / 있으면 안 나옴". 의뢰 완료·우두머리 처치·오프닝 선택도 표식을 남긴다. 저장 형식 버전 올림 (옛 저장도 불러온다) | 개발 모드에서 표식 목록 | 조건 붙은 이벤트를 쓸 수 있다 |
| G2. 말 섞기 | 마을에 "사람들과 말을 섞는다". 표식에 따라 소문이 바뀐다. 고유 의뢰 인물 재방문 대사. 서리항 먼저 | 마을 버튼 하나, 이야기 칸에 소문 2~3줄 | 마을이 내가 한 일을 안다 |
| G3. 서리항 사건 사슬 | G0에서 고른 떡밥으로 사슬 1~2개 (길 위 → 마을 사람 → 던전·적), 끝 보상은 이름 있는 물건. 하랄을 잡으면 해적 소굴이 바뀐다 | 일지에 "실마리" 칸 | 서리항에서 이어지는 이야기를 끝까지 따라간다 |
| G7. 동료 | 이르사가 G3 사슬 끝에서 빚을 갚으러 나타나 바로 함께 다닌다 (docs/world/story.md). 전투에서 직접 치지 않고 몇 턴에 한 번 거든다(물약·상처 묶기), 쓰러지면 마을에서 쉬어야 돌아온다. 길 위 이벤트에서 한마디 거든다. 호감도: 장면 선택 표식 + 숨은 신뢰 수치(거든 선택지를 따르면 오름) + 함께 걸은 길·넘긴 전투, 셋을 합쳐 대사와 장면이 갈린다. 크게 깎이는 선택은 없다. 시뮬레이션 봇에 동료를 넣는다 | 머리줄에 동료 체력, 전투에 동료 줄, 마을에 "보낸다 / 데려간다" | 둘이 다닌다 |
| ★1. 점검 | /playtest 서리항 한 바퀴 + `npm run sim`. 이어지는 이야기가 재밌는지, 단서가 얼마나 친절해야 하는지, 동료 때문에 너무 쉬워지지 않았는지 | | 같은 틀로 늘릴지 정한다 |
| G4. 네 지역으로 | 남은 세 지역에 사슬 하나씩 + 소문 + 재방문 대사. 지역마다 이벤트 3 → 5~6개, 결과 2 → 3~4가지 | 글만 는다 | 어느 지역에도 따라갈 이야기가 있다 |
| G5. 숨은 장소 | 지역마다 이름 있는 장소 2개. 길 위 "샛길" 단서로 찾고, 찾은 곳은 마을에서 곁길로 간다. 안은 방 1~2개 + 고정 사연 + 한 번짜리 이름 있는 보상 | 지도에 찾은 곳 표시, 마을 지도에 "알려진 곳" | 지도에 내가 찾은 곳이 는다 |
| G6. 세력 | 고분지기 형제단 (뼈울타리, docs/world/story.md): 가입 조건, 세력 의뢰 3단(사슬 틀), 자리에 따른 보상, 다른 세력·영주와의 관계는 소문으로 | 세력 건물 버튼, 일지에 세력 칸 | 한 세력에 들어가 자리를 올린다 |
| ★2. 점검 | /playtest + `npm run sim`. 네 지역·숨은 장소·세력을 더한 뒤의 흐름과 밸런스 | | G8~G10을 03에서 할지 04로 넘길지 정한다 |
| G8. 메인 첫 장 | 고정 장면 틀(data/opening.ts 방식) 3~4단계: 계기 → 뼈울타리의 누군가 → 정해진 고분 → 스토리 보스. 끝에 다음 장 떡밥 | 일지에 "큰 줄기" 칸, 고정 장면 화면 | 메인 첫 장을 끝까지 한다 |
| G9. 고대의 힘 | 옛 글자 엮기 (docs/world/story.md). 첫 장 보상으로 글자 둘 = 능력 하나. 전투 행동, 몇 걸음에 한 번. 숨은 장소에서 다음 글자를 찾는다 | 전투 버튼 "옛 글자", 짐 칸에 익힌 글자와 엮은 능력 | 룬과 다른 싸우는 방법이 생긴다 |
| G10. 마무리 | 시뮬레이션 다시 (동료·힘·이름 있는 보상·세력 보상, 골드가 더 쌓이는지). /playtest 오프닝부터 첫 장 끝까지. /consistency. 끝난 규칙을 game.md 로 | 없음 | 03 완료 |

순서 이유: 나머지가 모두 기억 장치에 기대서 G1이 먼저. 이야기 뼈대는 서브 사슬·세력·동료가 메인과 어긋나지 않게 맨 앞. 동료는 히로인이 빚을 갚으러 오는 자리가 서리항이라 G3 바로 뒤로 당기고, 밸런스는 ★1에서 본다. 고대의 힘은 뒤에 둬서 그 전까지 02의 밸런스를 지킨다. 서리항 한 곳에서 틀을 확인한 뒤 넓힌다.
