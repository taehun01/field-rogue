# 피치

가장 먼저 읽을 문서. 무엇을 왜 만드는지만 쓴다. 규칙은 docs/game.md, 세계는 docs/world/.

## 무엇을

도트 그래픽, 텍스트, 선택지만으로 만드는 스카이림 텍스트 판타지 RPG.
눈 덮인 북방의 여러 지역을 오가며 싸우고, 줍고, 의뢰를 받고, 던전에 들어간다. 쓰는 만큼 기술이 오르고 캐릭터가 자란다.
지도에서 목적지를 고르면 거리만큼 길을 걷고, 길 위에서는 고르는 대로 일이 벌어진다. 죽어도 저장에서 이어 간다.

## 방향

- 분위기와 장르 시스템, 세계·지명·종족은 스카이림과 비슷하게 간다.
- 처음부터 끝까지 기획하지 않고 작게 만들어 돌려 보며 방향을 잡는다.
- 이야기는 메인 스토리와 서브 스토리로 나누고, 보스는 그 스토리에 맞춰 나온다.

## 만드는 방식

- 웹 (TypeScript + Vite, 프레임워크 없음). — 텍스트·UI에 강하고, Claude가 브라우저로 직접 확인하며 만들 수 있고, PC와 모바일 모두 열려 있어서.
- 화면: 텍스트와 선택지 위주에 간단한 도트 그래픽.
- 배포: PC(exe) 우선, 모바일도 가능성을 열어 둔다. 포장 방식은 아직 안 정했다.
