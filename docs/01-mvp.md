# 01. MVP (첫 번째로 만들 최소 범위)

목표: 한 판 5~10분, 처음부터 죽거나 이길 때까지 돌아가는 것. 재미 판단은 이걸 돌려본 다음에 한다.
모든 항목은 기본안이며 만들면서 바꿔도 된다.

## 한 판의 흐름
1. 새 필드가 만들어진다 (작은 크기)
2. 필드를 칸 단위로 이동하며 탐험한다
3. 칸에서 전투 / 이벤트 / 휴식 / 상점 / 던전 입구를 만난다
4. 던전에 들어가면 짧은 방 몇 개를 지나 던전 보상을 얻는다
5. 보스를 쓰러뜨리면 승리, 체력이 0이 되면 처음부터

## 캐릭터
- 체력, 공격력, 방어력, 골드, 소지품 몇 칸

## 전투
- 단순 턴제: 공격 / 방어 / 아이템 / 도망

## 첫 목표 분량
- 적 3종, 보스 1
- 아이템 5개
- 이벤트 3개
- 던전 1종

## 나중에 (MVP에서는 하지 않음)
- 회차 보상, 메타 진행
- 세계관과 스토리
- 사운드
