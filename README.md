# text-skyrim (가칭)

도트 그래픽, 텍스트, 선택지만으로 만드는 스카이림풍 오리지널 판타지 RPG. 지도에서 목적지를 고르면 거리만큼 길을 걷고, 길 위에서는 고르는 대로 일이 벌어진다. 쓰는 만큼 기술이 오르고, 죽어도 저장에서 이어 간다.

- 지금 만드는 것: docs/pitch.md
- 지금 게임 규칙: docs/game.md
- 세계관: docs/world/
- 목표별 계획: docs/goals/
- 다음에 정할 것: docs/open-questions.md
- 구현: 웹 (TypeScript + Vite, 프레임워크 없이)

```
npm run dev     # 개발 서버
npm test        # 테스트
npm run sim     # 밸런스 시뮬레이션
```
