# 01. MVP (첫 번째로 만들 최소 범위)

목표: 한 판 5~10분, 처음부터 죽거나 이길 때까지 돌아가는 것. 재미 판단은 이걸 돌려본 다음에 한다.
모든 항목은 기본안이며 만들면서 바꿔도 된다.

## 한 판의 흐름
1. 새 판이 시작된다
2. 지도도 지역도 없다. 지금 상황에서 고를 선택지 2~3개가 짧은 단서와 함께 나온다
3. 고르면 전투 / 이벤트 / 휴식 / 상점 / 던전 입구 중 하나가 벌어지고, 끝나면 다음 선택지가 나온다
4. 던전에 들어가면 짧은 방 몇 개를 지나 던전 보상을 얻는다
5. 고른 선택에 따라 보스가 나타난다. 보스를 쓰러뜨리면 승리, 체력이 0이 되면 처음부터

## 캐릭터
- 체력, 공격력, 방어력, 골드, 소지품 몇 칸

## 전투
- 단순 턴제: 공격 / 방어 / 아이템 / 도망

## 체크리스트
- [ ] 선택지 진행 (선택지 2~3개 + 단서, 되돌아가기 없음)
- [ ] 전투 (적 3종, 보스 1)
- [ ] 선택에 따른 보스 등장
- [ ] 아이템 5개
- [ ] 이벤트 3개
- [ ] 휴식 / 상점
- [ ] 던전 1종
- [ ] 승리와 사망 후 처음부터
- [ ] 한 판이 처음부터 끝까지 끊기지 않고 돌아간다

## 나중에 (MVP에서는 하지 않음)
- 회차 보상, 메타 진행
- 세계관과 스토리
- 사운드
