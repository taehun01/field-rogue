# 02. 1차 목표: 세계관과 기반 시스템

> **완료.** F0~F8을 끝냈다 (PR #1, 커밋 7e11744). "지역마다 이벤트 채우기"만 남아 03 목표 G4로 넘겼다 (docs/goals/03-living-world.md).
> 이 문서는 계획과 체크리스트 기록이다. 지금 게임 규칙은 docs/game.md 를 본다.

목표: 스카이림풍 오리지널 세계관을 정하고, 그 위에서 돌아갈 기반 시스템을 만든다. 다 되면 오프닝부터 시작해 여러 지역을 오가며 캐릭터를 키우는 한 판이 돌아간다.
이야기 줄기(메인·서브 스토리, 세력, 고대의 힘 같은 것)와 스토리 보스는 이 범위 밖이다. 모든 항목은 기본안이며 만들면서 바꿔도 된다. 숫자는 코드에 `[임시값]` 주석.

## 한 판의 흐름 (계획 당시)
1. 고정 오프닝: 죄수선에서 간수가 출신을 물을 때 종족을 고르고, 난파 뒤 같은 배의 죄수와 함께 무너진 고분(정해진 방 3개 + 우두머리)을 지나며 은신·룬·강타를 써 본다. 오프닝 안에서는 지더라도 죽지 않고 장면이 이어진다 (개발용 "바로 시작" 버튼으로 건너뛸 수 있다)
2. 첫 지역(서리항)의 마을에 도착한다. 지도에서 이웃한 지역을 고르면 길을 떠난다
3. 길은 거리만큼 걸음이 걸리고, 걸음마다 MVP처럼 선택지 2~3개 + 단서가 나와 전투 / 이벤트 / 모닥불 / 떠돌이 상인 / 던전 입구 같은 무작위 조우가 벌어진다. 길 앞쪽 절반은 떠난 지역, 뒤쪽 절반은 갈 지역의 조우다. 걸음을 다 채우면 도착한다. 도중에 되돌아갈 수 있다 (지금까지 걸은 만큼 다시 걷는다)
4. 던전은 길 위 조우로 들어간다. 방을 지나 마지막 방의 우두머리를 쓰러뜨리면 보물을 얻는다
5. 마을에서는 여관에서 쉬고, 상인에게 사고팔고, 룬새김이에게 룬을 배우고, 게시판에서 의뢰를 받는다 (동시에 3개까지, 기한 없음, 포기 가능). 처치·던전 의뢰는 다른 지역 것도 나오고, 해내면 의뢰를 준 마을로 돌아가 보상을 받는다. 배달은 목적지 마을에 닿으면 끝난다
6. 싸우고 룬을 쓰고 몰래 다니고 흥정하면 그 기술이 오르고, 기술이 충분히 오르면 레벨이 오른다. 적도 플레이어 레벨에 맞춰 강해진다
7. 짐은 무게로 센다. 들 수 있는 무게를 넘으면 걸을 수 없으니 팔거나 버린다
8. 마을에 닿거나 여관에서 자면 저절로 저장된다 (1칸). 죽으면 마지막 저장에서 이어 가거나 새로 시작한다. 불러오면 무작위 결과는 새로 굴린다

## 구현 순서 (모두 완료)
각 단계가 끝나면 Taehun이 플레이해 보고 판단한다.

| 단계 | 할 일 | 끝나면 할 수 있는 것 |
|---|---|---|
| F0. 세계관 | 후보 → 선택 → docs/world/ | 글을 쓸 기준이 생긴다 |
| F1. 지도와 길 | 보스 시스템 삭제. 지도 화면(이웃한 지역끼리 길, 거리 5~10걸음), 목적지를 고르면 거리만큼 걷는 여행, 걸음마다 기존 선택지 규칙으로 무작위 조우(앞 절반은 떠난 지역, 뒤 절반은 갈 지역), 되돌아가기, 도착하면 임시 마을(여관·상점). 길 위 휴식은 모닥불만, 상점은 떠돌이 상인. 지역마다 단서·적 3종·이벤트 3개, 던전 끝 우두머리 | 지도를 보고 목적지를 골라, 길 위에서 일을 겪으며 간다 |
| F2. 종족 + 장비 | 캐릭터 만들기 화면(종족만 고름, 시작 수치·기술 보너스), 무기(한손·양손 × 등급)·갑옷 칸이 공격·방어를 정한다, 무게(넘으면 못 걷는다, 버리기), 바꾼 장비는 짐으로, 상점·던전 보상·전투 드롭(장비·잡동사니)과 팔기 | 시작이 판마다 다르고, 무엇을 들고 다닐지 고른다 |
| F3. 세 자원 + 마법 | 기력(강한 공격·도망), 마력(룬), 룬 3개(불꽃·치유·서리), 쉬면 다 차고 걸음마다 조금 찬다(전투 중엔 안 참), 치유 룬으로 시작하고 나머지는 룬새김이에게 산다 | 싸우는 방법을 고른다 |
| F4. 기술 성장 | 기술 6개(무기술·방어·파괴·회복·은신·흥정), 쓸 때마다 오름, 오른 합계로 레벨업, 레벨업 때 체력/기력/마력 중 고르기(기력이면 들 수 있는 무게도 늘어남), 은신(몰래 지나가기·기습), 20걸음 강화를 없애고 적이 플레이어 레벨에 맞춰 강해짐 | 캐릭터가 자란다 |
| F5. 마을과 의뢰 | 게시판(마을에 닿을 때마다 새 의뢰 3개 + 그 마을 고유 의뢰 1개), 동시에 3개까지. 처치(다른 지역 적도, 몰래 지나간 적은 안 셈)·배달(무게 있는 물건, 버리거나 팔면 실패)·던전(그 지역 던전 우두머리), 보상은 골드 + 가끔 장비, 기한 없음·포기 가능. 일지(진행 중 의뢰 + 지난 일) | 돌아다닐 목적이 생긴다 |
| F6. 저장 | 상태 저장(형식 버전 포함), 자동 저장만(마을 도착·여관), 1칸, 죽으면 이어 하기 / 새로 시작, 불러오면 난수 새로 | 죽어도 이어 간다 |
| F7. 오프닝 | 죄수선(간수 질문에 종족 고르기) → 유빙·난파 → 동행 죄수와 무너진 고분(정해진 방 3개: 은신·룬·강타, 우두머리) → 서리항에서 헤어짐. 오프닝 안에서는 죽지 않음. 개발 모드에만 바로 시작 버튼 | 한 판이 이야기로 시작한다 |
| F8. 밸런스 | 로직만 돌리는 수천 판 시뮬레이션(평균 생존, 레벨 곡선, 무게가 차는 속도, 골드 수입·지출, 의뢰 완료 속도), /playtest 한 번. 목표: 초반 죽는 비율은 지금 그대로, 레벨이 오를수록 조금씩 쉬워짐. 골드 쓸 곳은 따로 만들지 않고 가격·보상으로 맞춘다 | 숫자를 근거로 조정한다 |

순서 이유: 지역이 모든 글의 그릇이라 먼저. 저장은 상태 모양이 굳은 뒤에. 오프닝은 종족·전투·지역이 다 있어야 쓸 수 있어서 마지막.
