# 꺼진 태양 (가제)

선택지형 텍스트 판타지 RPG 기획 프로젝트.

## 시작하기
1. 이 폴더에서 `git init` 후 첫 커밋 (커밋 = 세이브 포인트)
2. 이 폴더에서 `claude` 실행
3. 첫 요청 예시: `open-questions.md 보고 오늘 정할 거 하나 골라줘`

## 진행 단계
1. 핵심 고정: docs/00-pitch.md
2. 세계관과 문체: docs/01-world.md, docs/02-style.md
3. 핵심 루프와 시스템: docs/03-systems.md
4. 구조와 분량 예산: docs/04-route.md
5. 이벤트 템플릿 → 초안 → 직접 고쳐 쓰기: docs/events/
6. 숫자 검증 (간단한 자원 시뮬레이션)
7. /playtest 로 페이퍼 플레이테스트 → playtests/ 에 기록

## 작업 습관
- 세션 하나에 작업 하나. 끝나면 문서 반영 후 커밋.
- AI 초안은 절반 이상 버리고 나머지는 직접 고쳐 쓴다.
