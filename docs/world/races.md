# 종족

규칙(종족마다 시작 수치·시작 기술 보너스만 다름)은 docs/game.md "종족", 숫자는 src/data/races.ts.

| 종족 | 모습과 성격 | 방향 |
|---|---|---|
| 북방인 | 이 땅의 주인. 키 크고 단단하며 추위에 강하다 | 체력·무기 |
| 반거인 | 거인의 피가 섞인 크고 느린 사람들. 뼈의 골짜기 출신이 많다 | 체력 많음, 기력 적음, 짐을 많이 든다 |
| 눈요정 | 하얀 고원에 사는 창백하고 가는 요정. 룬을 잘 다룬다 | 마력·룬 |
| 늑대혈족 | 보름달이면 늑대가 되는 혈통의 사냥꾼. 사람들이 경계한다 | 기력·은신 |
