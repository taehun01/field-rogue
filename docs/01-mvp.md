# 01. MVP (첫 번째로 만들 최소 범위)

목표: 죽기 전까지 끊기지 않고 계속 돌아다닐 수 있는 것. 그렇게 돌아다니는 게 재밌는지는 이걸 돌려본 다음에 판단한다.
모든 항목은 기본안이며 만들면서 바꿔도 된다.

## 한 판의 흐름
1. 새 판이 시작된다
2. 지도도 지역도 없다. 지금 상황에서 고를 선택지 2~3개가 짧은 단서와 함께 나온다
3. 고르면 전투 / 이벤트 / 휴식 / 상점 / 던전 입구 중 하나가 벌어지고, 끝나면 다음 선택지가 나온다
4. 던전에 들어가면 짧은 방 몇 개를 지나 던전 보상을 얻는다
5. 고른 선택에 따라 보스를 만날 수도 있다 (승리 조건이 아닌, 보상이 큰 강한 적). 만나는 길은 네 가지:
   - 징조: 선택지 단서에 가끔 징조가 섞이고, 징조가 있는 선택을 3번 고르면 보스와 마주친다
   - 소문: 싸우거나 위험한 선택을 할 때마다 숨은 수치가 오르고, 기준을 넘으면 보스가 먼저 찾아온다
   - 우연: 드물게 보스 선택지가 무작위로 섞여 나온다
   - 던전: 던전 안에서 "더 깊이 들어간다"를 고르면 보스와 만난다
6. 엔딩은 없다. 2~5를 반복하다가 체력이 0이 되면 처음부터

## 캐릭터
- 체력, 공격력, 방어력, 골드, 소지품 몇 칸

## 전투
- 단순 턴제: 공격 / 방어 / 아이템 / 도망

## 체크리스트
- [x] 선택지 진행 (선택지 2~3개 + 단서, 되돌아가기 없음)
- [ ] 전투 (적 3종, 보스 1) — 적 3종 완료, 보스는 7단계
- [ ] 선택에 따른 보스 등장 (징조 / 소문 / 우연 / 던전)
- [x] 아이템 5개
- [x] 이벤트 3개
- [x] 휴식 / 상점
- [x] 던전 1종
- [x] 사망 후 처음부터
- [ ] 죽을 때까지 끊기지 않고 돌아간다

## 구현 순서
| 단계 | 할 일 | 끝나면 할 수 있는 것 | 체크리스트 |
|---|---|---|---|
| 0. 뼈대 (완료) | Vite + TS, vitest, 시드 난수, 폴더 구조 | 빈 화면이 뜬다 | – |
| 1. 장면-선택지 루프 (완료) | 게임 상태(체력, 공격, 방어, 골드, 소지품)와 "장면 = 글 + 선택지 → 다음 상태" 구조, 최소 UI(본문, 버튼, 상태 바) | 버튼을 눌러 장면이 넘어간다 | – |
| 2. 선택지 진행 (완료) | 다음 선택지 2~3개 + 단서를 뽑는 규칙, 되돌아가기 없음 | 고르는 대로 계속 나아간다 | 선택지 진행 |
| 3. 전투 + 사망 (완료) | 공격 / 방어 / 아이템 / 도망, 적 3종, 체력 0이면 처음부터 | 죽을 때까지 끊기지 않는 한 판 (첫 이정표) | 전투, 사망 후 처음부터 |
| 4. 휴식, 상점, 아이템 5개 (완료) | 골드를 쓸 곳과 회복 수단 | 자원을 두고 고민한다 | 아이템, 휴식/상점 |
| 5. 이벤트 3개 (완료) | 이벤트를 데이터 파일로 분리, 구조·선택지·문장 작성(Claude, Taehun은 플레이하며 판단) | 사건을 겪는다 | 이벤트 |
| 6. 던전 1종 (완료) | 방 3~5개(숨김), 방마다 갈림길 단서 2개, 중간에 나가면 보상 없음, 전투 재사용, 던전 전용 이벤트 4개, 마지막에 골드 + 아이템(가끔 던전 전용 단단한 심장) | 던전에 들어간다 | 던전 |
| 7. 보스와 네 가지 길 | 보스 1, 징조 / 소문 / 우연 / 던전 깊은 곳. 길마다 켜고 끌 수 있게, 세부는 임시값 | 선택에 따라 보스를 만난다 | 보스 등장 |
| 8. 밸런스와 플레이테스트 | 로직만 돌려 수천 판 시뮬레이션(평균 생존 선택 수, 보스를 만나는 시점), /playtest | 숫자를 근거로 조정한다 | 끊기지 않고 돌아간다 |

## 나중에 (MVP에서는 하지 않음)
- 회차 보상, 메타 진행
- 세계관과 스토리
- 사운드
- 걸음이 늘수록 적 이름도 무서워지기 (예: 초반 늑대 → 후반 가고일). 지금은 이름은 그대로 두고 체력·공격만 20걸음마다 +10%
- 이벤트 결과 가짓수 늘리기: 구조는 그대로 두고, 고를 거리마다 결과를 지금 2개에서 3~4개로 늘려 같은 선택도 예측하기 어렵게
